# Smart Helmet System with ESP32

A safety helmet that uses an ESP32-S3, ADXL345 accelerometer, HC-SR04 
ultrasonic sensor, and IR sensor to detect falls, nearby obstacles, and 
unsafe riding conditions in real time.

## Components Used
- ESP32-S3
- ADXL345 (accelerometer — fall detection)
- HC-SR04 (ultrasonic — proximity/obstacle detection)
- IR sensor

## How it works
- Continuously monitors accelerometer data to detect sudden falls
- Uses ultrasonic sensing to detect nearby obstacles
- Outputs alerts via Serial Monitor

## Status
Personal/university project — built as part of learning embedded systems 
and sensor integration.
